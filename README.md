# TCG Tracker

A trading card game tracker. Built with the same stack as [game-tracker](../game-tracker).

## Tech stack

- **Frontend:** React 19, TypeScript (strict), Vite 8, React Router 8
- **Backend:** Supabase (Postgres, auth)
- **Styling:** CSS with design tokens generated by Style Dictionary
- **Testing:** Vitest + Testing Library + MSW (unit), Playwright (e2e)
- **Component workshop:** Storybook with a11y addon
- **Quality:** ESLint (flat config), Prettier, Husky git hooks
- **Deploy:** Vercel (SPA rewrites + security headers)

## Getting started

```bash
npm install
npx playwright install   # one-time, for e2e tests
cp .env.example .env.local   # fill in Supabase credentials
npm run dev
```

Dev server runs on http://127.0.0.1:5174 (5173 is reserved for game-tracker).

## Scripts

| Script                            | Purpose                                               |
| --------------------------------- | ----------------------------------------------------- |
| `npm run dev`                     | Dev server + token watcher                            |
| `npm run build`                   | Type-check and production build                       |
| `npm run build:tokens`            | Regenerate `src/styles/tokens.css` from design tokens |
| `npm run test`                    | Unit tests (Vitest)                                   |
| `npm run test:e2e`                | End-to-end tests (Playwright)                         |
| `npm run lint` / `npm run format` | Lint / format                                         |
| `npm run storybook`               | Component workshop on port 6006                       |

## Structure

```
src/
  components/   # Reusable UI components
  hooks/        # Custom React hooks
  lib/          # Clients and domain logic (supabase.ts)
  pages/        # Route-level components
  services/     # Data access / API wrappers
  styles/       # design-tokens.json + generated tokens.css
  test/         # Test setup and utilities
tests/          # Playwright e2e specs
supabase/       # Migrations and local config
```
